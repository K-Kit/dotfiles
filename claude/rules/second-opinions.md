# Fable Second Opinion

When a second opinion is worth its cost — the same approach has failed twice, a high-ambiguity design call, corroborating a high-stakes conclusion — reach for a model from a **different family**, not another call to the one already stuck. As of 2026-07-27 that is Fable, via the Agent tool's `model: "fable"`; if the Agent tool no longer offers a non-Opus/Sonnet family, this rule has nothing to point at and should be deleted rather than updated.

Unlike `advisor`, Fable has no memory of the conversation — brief it as a fresh subagent with full self-contained context.
