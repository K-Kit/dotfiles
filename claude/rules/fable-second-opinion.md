# Fable Second Opinion

Fable 5 (`claude-fable-5`) is a different Claude model family — reach it via the Agent tool's `model: "fable"` for a genuinely independent second opinion: the same approach has failed twice, a high-ambiguity design call, or corroborating a high-stakes conclusion.

Unlike `advisor`, Fable has no memory of the conversation — brief it as a fresh subagent with full self-contained context.
